# PhoneShare

Экран и звук Android-телефона на ПК по Wi-Fi. Смотреть можно в браузере (ничего не ставить на ПК) или
в приложении для Windows. ADB и режим разработчика не нужны.

## Скачать

Последняя версия: [Releases](https://github.com/RellayYC/PhoneShare/releases/latest).

| Файл | Что это |
|---|---|
| `PhoneShare-x.y.z-x64.msi` | установщик для Windows 10/11 (64-бит): для текущего пользователя, без прав администратора |
| `PhoneShare.exe` | то же приложение одним файлом, запускается из любой папки без установки |
| `PhoneShare.apk` | приложение для телефона (Android 10+) |

Оба приложения обновляются сами: проверяют GitHub при запуске (ПК ещё и раз в 6 часов) и предлагают
кнопку «Обновить». Обновление ставится, только если его подпись сошлась с ключом, зашитым в приложение.

## Телефон

1. Поставь `PhoneShare.apk` (Android спросит разрешение на установку из этого источника). Дальше
   обновления приходят в само приложение: при первом обновлении Android один раз попросит разрешить
   PhoneShare устанавливать приложения.
2. Открой PhoneShare, выбери качество, нажми «Начать трансляцию» и разреши запись экрана.
3. На экране появятся адрес (например, `http://192.168.1.23:8080`) и PIN из 6 цифр.

Звук передаётся с Android 10 и продолжает играть на телефоне. Приложения, которые запрещают запись
(банки, видео с DRM), Android показывает чёрным: это ограничение системы.

## ПК: браузер

Открой адрес с экрана телефона в Chrome, Edge или Firefox и введи PIN. Подойдёт любой компьютер в той же
сети Wi-Fi. Запись (R) сохраняется в загрузки, файлом WebM.

## ПК: приложение для Windows

1. Поставь `PhoneShare-x.y.z-x64.msi` (ярлыки появятся в «Пуске» и на рабочем столе) или просто запусти
   `PhoneShare.exe` из любой папки. Права администратора не нужны ни там, ни там.
   MSI ставит в `%LOCALAPPDATA%\Programs\PhoneShare`; другая папка задаётся так (обновления её запомнят):
   `msiexec /i PhoneShare-x.y.z-x64.msi INSTALLFOLDER=W:\PhoneShare\`.
2. Телефон с запущенной трансляцией появится сам: карточка в форме телефона, после первого показа — с кадром
   его экрана. Нажми на карточку и введи PIN. С галочкой «Запомнить» PIN в следующий раз не спросят.
3. В плеере: F — полный экран (Esc — выход), M — звук, S — скриншот в «Изображения\PhoneShare»,
   R — запись со звуком в «Видео\PhoneShare», «1:1» — пиксель в пиксель, кнопка «Поверх всех окон».

Если в сети нет ни одного телефона, PhoneShare сразу показывает, что проверить: запущена ли трансляция,
в одной ли сети ПК и телефон (с названием сети и адресом ПК), не гостевая ли сеть, не включён ли VPN, и
даёт ввести адрес с экрана телефона вручную.

Удаляется установленная версия как обычно: «Параметры → Приложения». Настройки остаются в
`%LOCALAPPDATA%\PhoneShare`. Переменная среды `PHONESHARE_HOME` переносит их, кэш WebView2, скриншоты и записи
в другую папку, например `W:\PhoneShare\Data`.

Нужен компонент Microsoft WebView2: в Windows 11 он уже есть. В Windows 10 PhoneShare покажет кнопку
загрузки, если компонента нет.

### Без приложения на телефоне (Miracast)

Телефоны с Miracast (Samsung «Smart View», Xiaomi/Huawei «Трансляция» и другие) могут показать экран
без PhoneShare на телефоне, через встроенный приёмник Windows. На главном экране приложения есть
раздел «Нет приложения на телефоне?»:

- если в Windows есть компонент «Беспроводной дисплей», кнопка откроет приёмник;
- если нет, кнопка откроет «Параметры → Проецирование на этот компьютер», где его добавляют
  (нужны права администратора).

Дальше на телефоне: шторка → «Трансляция» / «Smart View» → имя этого ПК. Задержка будет выше, чем с
приложением, на Google Pixel Miracast нет, а у ПК должен быть Wi-Fi с поддержкой Miracast.

## Безопасность

- Поток идёт только по локальной сети и **не шифруется**: не включай трансляцию в публичном Wi-Fi.
- Смотреть можно только с PIN. После 5 неверных попыток адрес блокируется на минуту, зрителей не больше 8.
  Кто смотрит, видно на телефоне. «Новый PIN» действует для следующих подключений: сохранённый старый PIN
  больше не подойдёт, но тот, кто уже смотрит, останется до конца сеанса. Чтобы отключить всех сразу,
  останови и снова начни трансляцию.
- Ключи (подпись APK и подпись обновлений) в репозитории не лежат: сборка берёт их из `W:\Keys\PhoneShare`
  (или из папки в `PHONESHARE_KEYS`). Потерять их нельзя: без ключа APK телефон не примет обновление поверх
  старой версии, без ключа обновлений приложения не поверят новому выпуску.

## Сборка

Нужны JDK 21 (`W:\jdk`), Android SDK в `.tools/android-sdk` (platform 36, build-tools 36.1.0),
.NET SDK 8, WiX 5 (`installer/build.ps1` сам ставит его в `.tools\wix`), Node 24, ffmpeg (для тестов).
Версия всего проекта одна, в файле `VERSION`.

```bash
powershell -File android/build.ps1
```

```bash
powershell -File desktop/build.ps1
```

```bash
powershell -File installer/build.ps1
```

Выпуск новой версии: собирает всё, подписывает `latest.txt`, ставит тег и публикует релиз (нужен `gh`):

```bash
node installer/release.mjs 1.0.1 "Что нового"
```

Проверки лежат в `dev/`, каждая запускается одной командой, например:

```bash
node dev/desktop-e2e.mjs
```

```bash
node dev/update-e2e.mjs portable
```

`dev/FakePhone.java` изображает телефон на ПК (тестовая картинка и тон 440 Гц) и нужен для проверок без
живого телефона.
